## 리틀리 편집 요령 (2026-11-22 밤에 넣어 보고 알게 된 것)

- 고친 것은 저장 단추 없이 바로 공개 페이지에 반영된다 — 고친 뒤 https://litt.ly/edit.h 를 새로 열어 확인.
- 링크 블록에 주소를 넣으면 리틀리가 그 페이지의 제목·그림(링크 미리보기)으로 **대표문구와 썸네일을 덮어쓴다** → 주소를 먼저 넣고, 그다음 문구를 다시 넣고 그림을 지운 뒤 올린다.
- 입력칸에 '·'가 든 한글을 타자로 넣으면 블록을 접을 때 '·' 뒤가 잘릴 수 있다 → 값을 직접 넣고(form_input) 끝에서 한 글자 쳤다 지운 뒤 블록 머리글을 눌러 접는다.
- 배너는 '갤러리' 블록(한 장씩 보기·이미지 비율 유지·연결 URL), 버튼 두 개는 '그룹 링크'(기본 배치), 구독 버튼은 '단일 링크' + '강조'(화면 아래 고정 단추가 된다 — 버튼색 '부분 적용'이면 이 단추만 주황).
- '광고' 블록은 운영자가 켜 둔 것(수익 계좌 연결) — 끄거나 지우지 않는다.
- 11/22 밤 운영자 '세 가지 다 해 줘'로 더 고침: 구독 버튼 레이아웃 '중간 카드'(다른 두 버튼보다 크게), 프로필 옵션 '협업 제안 받기' 끔(구독보다 먼저 눈에 띄던 단추).
- **⚠ 다른 곳에 열린 리틀리 편집 화면이 옛 내용으로 통째로 덮어쓸 수 있다** — 11/22 밤 '세 가지' 고침(구독 버튼 중간 카드·협업 제안 끔)과 안내 문구 뒷부분이 한 시간쯤 뒤 예전 상태로 돌아가 있었다(어디서 저장됐는지는 모름 — 휴대폰 앱이나 열어 둔 탭). 고친 뒤에는 편집 탭을 닫고 10초 뒤 공개 페이지를 다시 열어 확인하고, 운영자에게는 '다른 기기의 리틀리 편집 화면은 닫아 달라'고 말한다.
- 11/22 밤 다시 고침 + '오늘 아침 소식 먼저 보기' 주소를 `…/edit-h-archive/#latest-title` 로(최근 호 카드로 바로). `latest.html` 이 생기면 그 주소로 바꾼다(HANDOVER 7-1).
