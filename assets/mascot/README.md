# EDIT H 마스코트 — 안경 동그라미 'H'

2026-11-01 운영자 요청 "마스코트 캐릭터 만들어 줘".
2026-10-31 경쟁 비교 2차에서 나온 빈칸을 채우려고 만들었다 — 잘 되는 매체(트렌드어워드 '테드', 안장출근길 '안장', 뉴닉 '고슴이')에는 **얼굴과 목소리**가 있는데 우리 카드는 누가 말하는지 보이지 않는다(`automation/reviews/2026-10-31-competitors.md`).

## 고른 과정

- 힉스필드(GPT Image 2.5)로 시안 3방향 × 2장을 만들었다: A 안경 동그라미, B H 글자 몸통, C 신문·편지.
- 운영자가 A 의 두 장(신문 든 1번·숫자 가리키는 2번)을 두고 고민했다. 두 장은 같은 캐릭터의 다른 자세라 둘 다 기준 그림으로 넣어 생김새를 하나로 맞췄다.
- 이유: 지금 프로필·팔로우 카드의 안경 마크가 그대로 살아 움직이는 모양이라 이미 본 사람이 알아본다. 작게 줄여도 읽힌다.
- 크레딧: 시안 9 + 자세·시트 18 = 약 27(Ultra 요금제).

## 생김새 (바꾸지 않는다)

- 몸통 = 머리: 완전한 원 하나, 주황(브랜드 `#FF5233`), 테두리 없음
- 안경: 굵은 검정 동그라미 두 개를 짧은 일자 다리로 이음. 흰 렌즈 + 둥근 검정 눈동자. 몸 너비의 약 2/3, 위쪽 절반에
- 입: 안경 아래 작은 곡선 미소(놀람은 작은 동그라미)
- 팔: 가는 검정 막대 + 둥근 검정 손. 다리: 가는 일자 검정 막대 + 둥근 검정 발
- 납작한 2D 벡터, 단색, 그러데이션·그림자 없음

## 쓰는 원칙

- **캐릭터다, 사람인 척하지 않는다** — 'AI 에디터'나 실제 기자처럼 소개하지 않는다. 말풍선 문장은 지금 '에디터 H' 말투(해요체, 숫자·출처 우선)를 따른다.
