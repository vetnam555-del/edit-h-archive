**토큰·비밀번호는 채팅에 붙여 넣지 말고 GitHub → Settings → Secrets and variables → Actions 에만 넣는다.**
끝낸 항목은 ✅ 로 바꿔 두면 일요일 개선 루틴이 다음 단계로 넘어간다. (2026-10-02 작성 — 성장 검토 후속)

- [ ] **팔로워 목록 점검** — 프로필 → 팔로워 → 최근 순. 10/1~10/2 무렵 한꺼번에 늘어난 팔로워 중 **게시물 0·프로필 사진 없음·외국어 스팸 이름**이
  많으면 그 계정 옆 ⋯ → **팔로워 삭제**. 팔로워 늘리기 서비스·맞팔 이벤트를 쓴 적이 있다면 멈춘다(반응 없는 팔로워는 도달을 깎는다).
  대략 몇 명이 그런지 알려 주시면 성과표 해석에 반영한다.
- [ ] **하루 15분 직접 소통**(자동화가 대신하면 안 되는 일) — 비슷한 독자를 가진 계정(머니그라피·어피티·뉴닉 등) 게시물에 진짜 댓글 2~3개,
  우리 게시물에 달린 댓글엔 1시간 안에 답. 새 계정 초반엔 이것이 가장 확실하게 '보는 사람'을 늘린다.
- [ ] (선택·비용) **반응이 가장 좋은 릴스 1개를 '게시물 홍보'** — 하루 5천~1만 원 × 3~5일, 대상 한국 20~39세. 실제 2030 팔로워를 모아
  반응하는 팔로워 비중을 높인다. 하실지 알려 주시면 어떤 릴스를 고를지 성과표로 골라 드린다.

- [ ] **인스타 계정 상태 확인** — 인스타 앱 → 프로필 → ☰ → 설정 → 계정 → **계정 상태**.
  '추천 가능한 콘텐츠'에 경고가 없는지 본다. 경고가 있으면 화면을 캡처해 알려 주세요(음원 신고·가이드라인 위반이면 릴스가 비팔로워에게 안 보인다).
- [ ] **인스타 프로필 링크를 `…/edit-h-archive/subscribe.html?ref=ig` 로** — 인스타 경유 구독이 성과표 '구독 경로'에 따로 잡힌다(API 로는 못 바꾼다).
- [ ] **인스타 소개글 한 줄 바꾸기**(10/5~ 구독 선물) — 예: `🎁 구독하면 4분기 돈·일 체크리스트 ↓` 를 링크 바로 위 줄에.
  캡션이 '프로필 링크에서 구독하면 선물'이라고 안내하므로, 소개글·링크가 맞아야 전환이 생긴다.

## 구독 즉시 반영 (10분 — 2026-10-09 요청 '이메일을 적으면 바로 뉴스레터')

코드는 준비됐다: 새 구독자에게 환영 메일 + **가장 최근 호를 바로** 보낸다(`sync_subscribers.py`). 지금은 매시간 예비 실행이라
신청 뒤 길게는 몇 시간 걸린다(GitHub 예약이 늦을 때). 아래를 하면 **신청 뒤 2~3분**으로 줄어든다.
- [ ] **Gmail 에 '구독 알림 → 바로 실행' 스크립트 달기** — 순서는 `automation/relay/subscribe_relay.gs` 맨 위 주석(1~5단계).
  GitHub 토큰은 **이 저장소의 Actions 쓰기 권한만** 있는 fine-grained 토큰으로, Apps Script 스크립트 속성에만 넣는다(채팅·코드 금지).
  끝나면 구독 페이지로 본인 메일을 한 번 신청해 보고 몇 분 걸렸는지 알려 주시면, 페이지 문구를 '몇 분 안에'로 바꾼다.

## 스레드(Threads) 자동 게시 켜기 (20분 — 코드는 준비돼 있음: `automation/post_threads.py`, 매일 12:30)

1. 스레드 앱에서 인스타 계정(@edit.h.kr)으로 **스레드 프로필**을 만든다.
2. <https://developers.facebook.com/apps> → **앱 만들기** → 사용 사례 **'Threads API 액세스'** 선택 → 앱 이름 예: `EDIT H Threads`.
3. 앱 대시보드 → 사용 사례 → Threads API 액세스 → **맞춤 설정** → 권한에서 `threads_basic`, `threads_content_publish` 추가.
4. 앱 역할 → **역할 → Threads 테스터**에 스레드 계정 추가 → 스레드 웹(threads.net) → 설정 → 계정 → **웹사이트 권한 → 초대**에서 수락.
5. 사용 사례 맞춤 설정 화면 아래 **'사용자 토큰 생성기'** → 스레드 계정 옆 **토큰 생성** → 표시된 토큰(60일짜리)을 복사.
6. GitHub → Settings → Secrets → Actions → **New repository secret** → 이름 `THREADS_ACCESS_TOKEN`, 값 = 토큰.
7. 확인: Actions → **Post EDIT H to Threads** → Run workflow(mode `check`) → '스레드 계정 @…' 이 나오면 끝.
   그 뒤로 매일 12:30 에 자동으로 올라가고, 토큰은 일주일마다 자동 연장된다(GH_ADMIN_TOKEN 이 이미 있어 Secret 도 자동 갱신).

## 검색 노출 등록 (15분 — 2026-10-09 SEO 기본 적용 뒤)

호 페이지마다 설명문·대표 주소(canonical)·기사 구조화 데이터(NewsArticle)를 넣었다. 검색엔진에 사이트를 알리는 건 운영자 계정이 필요하다.
- [ ] **구글 서치 콘솔**(search.google.com/search-console) → 속성 추가 → 'URL 접두어'에 `https://vetnam555-del.github.io/edit-h-archive/`
  → 확인 방법 'HTML 태그' 를 고르면 `<meta name="google-site-verification" content="…">` 가 나온다 — 그 content 값만 채팅으로 알려 주면
  `index.html` 에 넣어 드린다(공개돼도 되는 값). 확인 뒤 Sitemaps 에 `sitemap.xml` 제출.
- [ ] **네이버 서치어드바이저**(searchadvisor.naver.com) → 사이트 등록 → 같은 방식(HTML 태그 `naver-site-verification`) → 요청 → 사이트맵 제출에 `sitemap.xml`, RSS 제출에 `feed.xml`.
- 참고: `github.io/edit-h-archive` 주소는 robots.txt 를 둘 수 없는 하위 경로라 사이트맵은 위 두 곳에 직접 제출해야 한다.
