| 꾸밈 | 마스킹테이프·폴라로이드·스프링 노트 |

가이드 그림 4장의 요지:
1. 첫 장은 내 계정의 방향에 맞게 고른다. 같은 주제도 전할 정보·이미지에 따라 맞는 배치가 다르다.
2. 분위기를 보여 주려면 사진을 크게, 정보를 또렷이 나누려면 카드 안에 사진을 담는다.
3. 한 장의 사진은 대상을 크게, 두 장은 다른 모습·디테일을 함께. 준비한 사진 수와 내용에 맞춰 고른다.
4. **끝까지 읽은 독자에게 무엇을 남길까**: 이미지와 계정명을 중심으로, 어떤 콘텐츠를 전하는 계정인지·앞으로 어떤 이야기를 만날 수 있는지 한 문장으로.

### 1. 3:4(1080×1440) — 적용, API 확인 뒤

- **근거**:
  - 인스타 프로필 격자가 2025년 1월부터 3:4 다. 4:5 카드는 격자에서 좌우가 약 6%(양쪽 34px) 잘린다.
  - 3:4 게시는 2025년 5월부터 앱에서 된다. 피드에서 4:5 보다 6.7% 더 크게 보인다.
  - 템플릿도 모두 3:4 다.
  - 출처: [ZoomSphere 게시 요건](https://help.zoomsphere.com/en/articles/4852379-scheduler-image-post-requirements-for-ig-auto-publishing), [Lindsey Gamble](https://www.lindseygamble.com/blog/instagram-now-supports-34-aspect-ratio-for-photos-and-carousel-posts), [Neal Schaffer](https://nealschaffer.com/instagram-post-size/)
- **위험**: Meta 게시 API 문서에는 4:5~1.91:1 만 적혀 있다(3:4 를 받는다는 건 외부 도구 업체 글뿐). 확인 없이 바꾸면 08:30 캐러셀이 거절될 수 있다.
- **그래서**:
  1. `post-instagram.yml` mode=**probe-ratio** 로 1080×1440 시험 그림(`assets/probe/ratio-3x4.jpg`, 내용 없음)의 캐러셀 컨테이너만 만든다. 게시는 하지 않는다.
  2. 받으면 `config.instagram.card_ratio_from` 에 날짜를 넣는다. 그날부터 카드·주간 특집이 1440 으로 나간다.
  3. 표지 사진 검사·사진 고르기·스토리 카드 화면·카드식 릴스·갤러리 표시도 같은 날짜를 따른다(`common.card_height`).
- **늘어난 90px 처리**:
  - 숫자·말풍선 카드는 아래 기준이라 위가 조금 더 비는 정도다.
  - 핵심어 표지는 핵심어·스티커 자리를 45px 내리고 늘렸다.
  - 지난 4호(사진 표지·핵심어 표지·예비 호 포함)로 찍어 넘침 0 을 확인했다.
- **판정**: 캐러셀 24시간 도달·조회, 3:4 7호 vs 그 전 7호. 계정 격자에서 표지 제목이 잘리지 않는지 눈으로.

### 2. 마지막 장 → 팔로우 카드 — 10/31 부터

- **근거**:
  - 최근 14일 캐러셀을 보고 프로필 방문 2·팔로우 0 이다.
  - 지금 마지막 장의 행동 유도는 오른쪽 아래 옅은 글자 링크('팔로우 + 저장해두기>') 하나라 눈에 띄지 않는다.
  - 가이드 4(계정명 중심·한 문장 약속)와 엔딩 3·4(가운데 프로필 카드 + 검정 FOLLOW 버튼)가 정확히 이 빈칸이다.
- **바꾼 것**(`cards.cta_follow`, `follow_card_from`):
  - 저장 질문(오늘의 저장각)은 위에 그대로 둔다.
  - 가운데에 안경 마크 + `edit.h.kr` + "매일 아침 8시 30분, 2030 직장인의 돈·일·소비 뉴스 5가지" + 발행 숫자 3개 + **검정 '팔로우하고 내일 아침에 받기' 버튼**을 넣었다. 문구는 릴스 마지막 화면과 같다.
  - 아래에 뉴스레터 안내를 둔다.
  - 투표 날은 예전 마무리로 나간다.
- **판정**:
  - 캐러셀 프로필 방문·팔로우(도달당), 10/31~11/06 7호 vs 그 전 7호 → 11/08 개선 루틴.
  - 3:4 전환과 겹치면 도달은 바뀔 수 있다. 그래서 '도달당'으로 본다(지표가 겹치지 않게).

### 3. 첫 장 @계정 — 보류

화면 캡처·DM 공유로 표지만 돌 때 계정을 찾게 해 주는 장점이 있다. 하지만 표지는 '표지 비교'(사진/핵심어)를 재고 있어 지금 바꾸면 변수가 겹친다. 다음 실험 후보로 남긴다.

### 4. 첫 장 아래쪽 왼쪽 정렬 제목·카테고리 칩 — 보류

템플릿 표지 ④(사진 + 아래 그라데이션 + 흰 큰 제목)는 우리 사진 표지(위쪽 띠 제목)와 다른 문법이다. 어느 쪽이 나은지는 근거가 없다(가이드 1: 계정 방향에 맞게). 3:4·팔로우 카드 판정 뒤 A/B 후보로 둔다.

### 5. 사진 많은 중간 장 — 지금은 안 함

카드 라지·미디움·사진 격자는 소식마다 쓸 수 있는(라이선스가 확인된) 사진이 있어야 한다. 우리는 표지 한 장도 위키미디어에서 어렵게 찾는다(대체 사진 19장). 소식마다 사진을 붙이면 제작 시간과 라이선스 위험이 커진다. 금요일 주간 특집처럼 사진이 정해진 날에만 나중에 시험할 수 있다.

### 6. 글꼴·글자 크기·여백 — 그대로

- 기본 글꼴이 같다(Pretendard). 장식 글꼴은 브랜드 일관성과 글꼴 라이선스 때문에 쓰지 않는다.
- 템플릿 설명 32~36px·여백 75px 은 우리 본문 33px·여백 60~90px 과 같은 범위다. 바꿀 근거가 없다.
